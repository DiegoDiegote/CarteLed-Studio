# CarteLed Studio | Solución Integral para Cartelería LED y Corpóreos 3D

**CarteLed Studio** es la plataforma definitiva diseñada para profesionales de la cartelería, diseñadores y fabricantes que buscan optimizar el diseño, la simulación y la producción de carteles LED animados y letras corpóreas listas para impresión 3D.

---

## 📦 ¿Qué incluye este repositorio?

* **📥 CarteLed Studio FREE (Instalador `.exe`):** Software para diseñar y simular carteles LED animados sobre tiras WS2812B/SK6812 utilizando un controlador ESP32[cite: 3, 21]. *(Nota: La función de grabación directa al hardware está reservada para la versión PRO)[cite: 4, 21].*
* **📖 Manual de Usuario oficial (`.pdf`):** Guía completa paso a paso con esquemas de cableado, reglas de alimentación eléctrica (cálculo de fuentes y masas comunes) y manejo del panel WiFi[cite: 2].
* **🧊 Generador de Corpóreos 3D (WebApp `.html`):** Herramienta offline con visor 3D en tiempo real para transformar textos tipográficos o logotipos vectoriales `.svg` en cajas huecas y tapas difusoras en formato `.STL`[cite: 18, 19].

---

## 📥 Descargas y Accesos Directos

### 1. Software y Manuales
Podés descargar el paquete completo y listo para usar clonando o descargando este repositorio, o accediendo directamente a las carpetas:
* **Instalador:** `Carteled-Studio-FREE-Setup.exe`[cite: 21]
* **Manual del Usuario:** `CarteLed-Studio-Manual.pdf`[cite: 2]

### 2. Generador Web de Corpóreos 3D
Para utilizar la herramienta de conversión a `.STL` sin necesidad de conexión a internet:
1. Descargá el archivo `Generador_3D.html` y la carpeta de recursos `assets/` en tu computadora[cite: 18, 21].
2. Hacé doble clic en `Generador_3D.html` para abrirlo al instante en tu navegador web (Chrome, Edge, Firefox, Brave)[cite: 19].
3. Escribí tu texto o arrastrá un archivo `.svg`, ajustá las dimensiones (altura, profundidad, espesores de pared) y descargá los archivos `.STL` de la caja y el difusor listos para tu laminador (Cura, OrcaSlicer, Bambu Studio)[cite: 18, 19, 20].

## 💡 Características Principales de CarteLed Studio

* **Simulación Visual:** Visualizá los efectos dinámicos (arcoíris, fuego, respiración, cascada, ondas, meteoros) antes de aplicarlos[cite: 8].
* **Cálculo Automático de Consumo:** El software estima de forma inteligente los amperes necesarios según la cantidad de LEDs y añade márgenes de seguridad para evitar caídas de tensión[cite: 7].
* **Control por WiFi Integrado:** Una vez grabado el microcontrolador, el cartel levanta su propia red para cambiar efectos, brillo o configurar el sensor de luz LDR (brillo automático día/noche) directamente desde el celular sin instalar aplicaciones[cite: 3, 8, 14].
